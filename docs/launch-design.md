# Photographic portfolio direction

Reference: https://www.spaceship.com/ — studied for large photographic scenes, concise messages, overlapping scroll transitions, rounded actions and a progression from introduction to deeper information. No reference-brand graphics, branding, text or code were copied.

## Visitor flow

1. Introduce Privatus and the main actions.
2. Move through three photographic chapters: useful software, continued learning at MUST, and sharing knowledge.
3. Explain software services with an original modular illustration.
4. Explore recent articles, published series, guides, talks and the searchable archive.

The theme picker, Auto/Light/Dark handling, remembered choice, keyboard shortcuts and all palette values are unchanged. Scene lighting, overlays, text and buttons derive from the selected theme's tokens. The image assets keep their source colors, with CSS treatments that follow the selected palette.

Motion progressively enhances native scrolling. Chapters use CSS sticky positioning rather than scroll locking; reduced-motion visitors receive ordinary document-flow scenes. Links, article search and content remain functional without animation.
