## What you should be able to do
Turn reading into a question-led set of retrievable notes.

## Preparation and session plan
Recall the key definition and one example from the previous session before continuing. Allow about 75 minutes, including an independent attempt and correction. This is a proposed study session, not a university timetable.

## Core notes and worked example
Read with a question. First preview headings, definitions and examples. Then read a short section closely. Close it and reconstruct the main idea from memory. Finally, compare your reconstruction with the source and correct gaps. Copying paragraphs is a record of reading, not evidence of understanding.

Use a note structure with four fields: concept, own explanation, original example, question remaining. Record the source immediately so you can return to it. Mark uncertainties explicitly; a question mark is better than a confident error that becomes part of your revision.

Worked example: After reading about processes, write: "A process is an executing program with its own execution context and resources. Two launches of the same executable can be two processes. Question: what is shared between threads in one process?" This is more useful than copying a definition without an example.

For revision, turn a heading into a retrieval question. Replace "Ohm's law" with "When is V=IR a suitable model, and how do I check the units?"

## Reasoning in more depth
Start with the purpose of reading: which question should the source answer? Preview headings, then read for claims, definitions and evidence. Separate the author's statement from your interpretation and record enough reference information to find it again. After closing the source, write a short explanation from memory and identify a missing step. Rereading a highlighted paragraph feels familiar; reconstructing its reasoning reveals whether you can use it.

## Independent task | Attempt before reading the answer
Create a note template for a chapter about processes. Include fields that prevent confusing a quotation, a paraphrase and your own question.

## Worked answer and marking points
Use source title/author/page or section; reading question; exact quotation with quotation marks if needed; paraphrase in your own structure; supporting example; uncertainty; and retrieval question. A suitable retrieval prompt is: How does a running process differ from the executable stored on disk? Reopen the source to correct the answer after attempting it.

## Review and progression
Explain the objective from memory. Change one task input and justify the new answer. Record a correction and retry after a day and a week.
