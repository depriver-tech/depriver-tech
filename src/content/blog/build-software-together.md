I’m bringing together people who want to learn software engineering by building things together. If you’re curious about tech, learning to code for the first time, or already working on your own projects, you’re welcome.

**[Join on WhatsApp](https://wa.me/255752747681?text=I%E2%80%99m%20in%21%20I%E2%80%99d%20like%20to%20learn%20)** and tell us what you’d like to learn and when you’re usually available.

## One challenge every day

We’ll post a short coding task in the group chat every day, including weekends. Make time to try each task and share a solution, your progress or a question. If you commit to a session or project task, follow through and let the group know early if your plans change. Bring questions from class, an online course or your own projects. We’ll schedule online and in-person sessions around everyone’s availability.

## Our first full-stack project

We’ll build a study planner that lets users add assignments, set due dates and mark work complete. We’ll start with the interface, connect it to an API and save assignments in a database. We’ll rotate roles so everyone can try each part.

Along the way, we’ll use Git, review each other’s code and test the app. Aim to leave with a contribution you can show in a portfolio and explain in an interview.
